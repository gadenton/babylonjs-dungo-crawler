## 3. Caveats

- **WebAssembly in Headless Node vs Browser**: Node.js `tsx` scripts can execute Recast WASM if `wasm-compat` loads correctly, but browser environments handle WASM fetch over HTTP. Browser-based Playwright tests remain necessary for full runtime verification.
- **NullEngine Rendering Limitations**: Babylon's `NullEngine` bypasses WebGL shaders, SSAO2 post-processing, and GPU instancing rendering pipelines (`createInstance`). Visual tile placement and corner alignment must be verified manually or via visual regression tests in a real browser.
